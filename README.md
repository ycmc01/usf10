# 美股總經風險台（XQ 美股版 模組10：總經與跨資產風險）

依《XQ 美股版 模組10 總經與跨資產風險 產品規格書》（2026-10-17）實作 MVP：F36 經濟預期差與政策路徑、F37 信用／金融條件與流動性。F35 波動期限結構、F38 歷史回放依規格列第二期，未開發（但已在跨資產頁把美國 VIX 與台指 VIX 分開並列）。

- 啟動：桌面「美股總經風險台.bat」，或 `node server.js` → http://127.0.0.1:10505
- 測試：`npm test`（夏令時間換算、口徑換算與缺月、版本不覆寫與時點查詢、預期差文字與標準化、異常預估、缺漏與停更、百分位與最差 10%、公布後反應、持股配對相關、觀察條件、FOMC 與點陣圖解析）
- 零相依 Node 20+；可選環境變數 `FRED_API_KEY`（有金鑰時改走 FRED API，較不易被限流）

## 規則

1. **不覆寫**：每次擷取存成新版本（`data/db.json` 的 `vintages`），同一版本鍵不覆寫；內容與前一版相同不新增。
2. **時點查詢**：只取版本日 ≤ 查詢日；前值「公布前」取公布日前一天可得的版本，修訂另列。
3. **缺值不補**：未公布期間不寫 0、不插值，畫面顯示「未公布」與原因（2025-10 CPI：政府停擺）。
4. **來源衝突**：XQ 與 BLS 不同時以 BLS 為準，記入稽核日誌。實測多數差異在較早期間：BLS 已含年度季調修正，XQ 保留較早版本。
5. **時區**：公布時間存 UTC；XQ 只有日期，時間依機構慣例（美東 08:30／10:00、FOMC 14:00），標「依機構慣例時間」。
6. **預期差**：只用公布前的共識預估。XQ 欄位等於前值時標「無共識（XQ＝前值）」不計算；使用者可在公布前輸入共識並註明來源（公布後不可輸入）。標準化預期差＝預期差 ÷ 過去 24 次預期差標準差，樣本 < 6 不計算。
7. **待查**：預估與前值差 > 歷史期間變動 5σ、量級比 > 8 倍，或已開發經濟體物價年增率 > 15%（例：XQ 英國 PPI 年增率 26.5%）→ 隱藏數值顯示「待查」。
8. **停更**：序列超過 2 個週期未更新標「停更」（USGB0103 停在 2026-02 → 非農改用 BLS 與 EI020025）。
9. **不做**：不給衰退機率、不給綜合分數、不把點陣圖或市場價格當聯準會承諾、不以 ETF 價格反推利差。

## 限制

- XQ 日曆只給未來 14 天，過去的公布日與預估無法回補；本站從啟用日起累積，標準化預期差需累積共識樣本。
- 免費來源沒有市場共識預估；需授權資料源或使用者手動輸入。
- BEA（PCE、GDP）、ISM、Census、密大、經濟諮商會沒有免金鑰的官方 API，實績用 XQ；首次公布值用 ALFRED。
- ICE 信用利差的再發布條款、FRED 商業使用條款需法務確認（規格待確認事項 6）。
